# LunnaOS Sel(l)enne visual specification

The supplied Sel(l)enne 1.0 reference screens are the visual source of truth.

## Visual language

- Background: deep navy / midnight blue
- Accent: luminous violet and purple
- Secondary accent: cool blue
- Surfaces: translucent dark glass
- Corners: strongly rounded
- Borders: subtle violet/blue outlines
- Shadow: soft, deep and diffused
- Typography: clean modern sans-serif with high readability
- Icons: consistent outline/filled hybrid, large touch-friendly targets
- Motion: short, smooth, low-amplitude transitions

## Desktop

- Thin top bar
- Bottom centered translucent dock
- Right-side desktop icons
- Optional weather/focus widgets on the left
- Full-screen Sel(l)enne lake/mountain/galaxy wallpaper

## Core surfaces

### Action Center

Wi-Fi, Bluetooth, dark mode, night light, Do Not Disturb, game mode, volume, brightness, battery, media controls and current network.

### Launcher

Search field, pinned applications, categories and recent files.

### App Center

Featured applications, categories, installed applications, updates and library.

### Settings

System, Bluetooth, Network, Personalization, Applications, Accounts, Privacy & Security, Power, Display, Sound, Storage and About.

### Files

Home, Desktop, Documents, Downloads, Pictures, Music, Videos, Projects, Public, Trash and device/cloud entries.

### Notifications

Stacked glass cards with application icon, title, message, timestamp and contextual action buttons.

## Non-negotiable

The final implementation must reproduce the composition, spacing, translucency, glow, hierarchy and interaction model of the supplied references rather than merely applying a purple theme to an existing desktop.
